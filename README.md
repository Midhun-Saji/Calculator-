#  Calculator App

A responsive and interactive ** Calculator App ** built using **HTML, CSS, and JavaScript**.  
This project demonstrates DOM manipulation, event handling, and dynamic updates to the calculator display.

# Features
- Basic arithmetic operations   
- Addition
- Subtraction
- Multiplication
- Division 
- ( ) Brackets support  
- Clear & Delete functions  
- Responsive UI  

# Tech Stack
- HTML5  
- CSS3   
- JavaScript (ES6)  
- DOM Manipulation

# Learning Outcomes
- How JavaScript interacts with HTML elements through the DOM.  
- Handling user actions to dynamically update the calculator display.  
- Building responsive layouts with CSS.
